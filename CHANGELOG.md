# Changelog

All notable changes to this plugin are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.2.0] - 2026-10-02

### Added

- The plugin's settings show up in Obsidian's settings search (Obsidian 1.13 and later).
- The **Folder** and **Recordings folder** settings suggest folders from your vault as you type (Obsidian 1.13 and later).

## [0.1.2] - 2026-10-02

### Fixed

- The recorder dialog no longer shows Obsidian's close button out of line with the header on Obsidian 1.13 and later.

## [0.1.1] - 2026-09-24

### Fixed

- The recorder dialog no longer shows a second close button over the minimize button.

## [0.1.0] - 2026-09-24

### Added

- Floating mic button in the bottom-right corner for recording voice notes.
- Setting to show the button on all notes, only on notes in a folder, or only on notes with a tag.
- Optional ribbon icon that starts and stops recording for the open note.
- Recording controls with a timer, **Pause/Resume**, **Stop** and **Discard**.
- Recordings are saved to the attachment folder (or a custom folder) and embedded in the note where recording started.
- Commands: **Start recording**, **Pause recording**, **Resume recording**, **Stop and save recording**, **Start/stop recording**, **Pause/resume recording** and **Start/pause/resume recording**.
